## 三、舰艇BOSS部件（48张）

> 规格：60x60px PNG-32 RGBA，90度俯视，透明背景
> 炮塔会旋转，**每个炮塔需要8方向图**
> 防空炮/雷达等固定朝向的部件只需1张

| 舰艇 | 旋转部件(8方向) | 固定部件(1张) | 当前数量 | 应需数量 |
|------|-----------------|----------------|----------|----------|
| 天龙号 | 4炮塔 × 8方向 = 32张 | 0 | 4+4=8 | **32** |
| 妙高号 | 4主炮+2防空 = 6×8 = 48张 | 0 | 10+10=20 | **48** |
| 最上号 | 5炮塔(含舰桥) × 8方向 = 40张 | 0 | 10+10=20 | **40** |

> **注意**: 当前部件sprite只有1个方向(朝上)，如果炮塔需要旋转瞄准玩家，则每个旋转部件需8方向。
>
> **设计方案选择**：
> - **方案A（推荐）**：炮塔不旋转，始终朝上，用代码旋转sprite（Godot `rotate`属性），只需1张/部件
> - **方案B**：炮塔旋转，提供8方向图，每个旋转部件8张
>
> **如选方案A**：保持当前48张（含destroyed变体）不变  
> **如选方案B**：需扩充至约 (4+6+5)×8×2(含摧毁) = **240张** — 工作量巨大，不推荐

> **小计（方案A）：48张 60x60 PNG**（已有，无需改动）

**Roll 姿态规范**（参照参考图P-61）：
- **平飞 (`player_xxx.png`)**：机翼水平，机头朝上，标准90度俯视
- **左倾 (`player_xxx_roll_l.png`)**：左翼抬起、右翼下沉，机头朝上不变，整个机身可见左侧翼面变宽（表示正在向左移动）
- **右倾 (`player_xxx_roll_r.png`)**：右翼抬起、左翼下沉，机头朝上不变，整个机身可见右侧翼面变宽（表示正在向右移动）
- 倾斜角度约15~25度，不宜过大以免影响碰撞判定

> **小计：7x3 = 21张 128x128 PNG**（已有7张平飞，需新增14张roll变体）

## 十二、方向图命名规范建议

### 8方向命名（战斗机/坦克等）

```
{unit_id}_n.png    ← 北(朝上，默认)
{unit_id}_ne.png   ← 东北(45度)
{unit_id}_e.png    ← 东(朝右，90度)
{unit_id}_se.png   ← 东南(135度)
{unit_id}_s.png    ← 南(朝下，180度)
{unit_id}_sw.png   ← 西南(225度)
{unit_id}_w.png    ← 西(朝左，270度)
{unit_id}_nw.png   ← 西北(315度)
```

### 4方向命名（卡车/船只等）

```
{unit_id}_n.png    ← 北(朝上)
{unit_id}_e.png    ← 东(朝右)
{unit_id}_s.png    ← 南(朝下)
{unit_id}_w.png    ← 西(朝左)
```

### 代码侧加载方式

```gdscript
# 8方向旋转加载
var dir_names = ["n", "ne", "e", "se", "s", "sw", "w", "nw"]
var angle = global_position.direction_to(target).angle()
var dir_index = round(angle / (PI/4)) % 8
sprite.texture = load("res://assets/sprites/enemy/%s_%s.png" % [unit_id, dir_names[dir_index]])
```
