## 1. 地图设计思路梳理

### 1.1 已确定的卷轴策略（v1.6 确认）

| 层 | 循环方式 | 说明 |
|----|---------|------|
| **云层** | 无限循环 | 半透明云朵 PNG，`repeat_size` 循环，全关通用 |
| **海面/大江水面** | 无限循环 | `topdown_water.gdshader` 动态渲染，底色贴图循环 |
| **陆地地表底色** | 段内循环 | 段内无缝贴图循环铺底色，段间切换不循环 |
| **地标建筑** | 不循环 | 独立 PNG 挂在 Parallax2D 子节点，位置固定一去不返 |
| **地面作战单位** | 不循环 | MapObject 按 `map_spawn_y` 精确定位生成 |

> **用户确认**：除海上和空中云朵可循环外，其他地面元素一律不循环。地标和地面单位都是"一过性"的，飞过即不再出现。

### 1.2 分段地图与地面单位的配合

每关按时长拆为 2~4 段，段间切换时：
1. `MapObjectManager.clear()` 清空旧段所有活跃对象
2. 加载新段的 map JSON，`map_spawn_y` 从 0 重新计算
3. `bg_scroll_offset_y` 重置为 0
4. 地表贴图更换，地标集更换

### 2.2 各单位详细设计

#### 2.2.1 轻型坦克（light_tank）— 九五式轻战车 Ha-Go

**历史背景**：日军产量最大的装甲战斗车辆（约 2,300 辆），缅甸战场战车第 1/2/14 联队主力。37mm 炮无法击穿 M3 斯图亚特正面，但对中国战场无装甲目标威胁极大。

**游戏行为**：
- 从屏幕底部沿道路方向向上缓慢移动（speed = 30px/s）
- 每 3 秒炮塔旋转瞄准玩家并发射一发 37mm 炮弹（直线，伤害 1，速度 250px/s）
- HP 20，被击毁后爆炸特效 + 30% 概率掉落 P 道具

**场景结构**：
```
LightTank (Area2D, MapObject)
├── Sprite2D (type95_hago.png, 60×36)
├── TurretPivot (Node2D)  ← 炮塔旋转锚点
│   └── Sprite2D (type95_turret.png, 20×16)
├── CollisionShape2D (RectangleShape2D 60×36)
└── ShootTimer (Timer, 3.0s)
```

**JSON 配置示例**：
```json
{
  "id": "l05_light_tank_01",
  "type": "light_tank",
  "position": {"x": 300, "y": 1200},
  "properties": {
    "hp": 20, "score": 500,
    "move_speed": 30,
    "fire_interval": 3.0,
    "bullet_speed": 250,
    "bullet_damage": 1,
    "drop_chance": 0.3,
    "drop_types": ["power"]
  }
}
```

#### 2.2.2 中型坦克改（medium_tank_kai）— 九七改 Chi-Ha Kai

**历史背景**：九七式中战车换装 47mm 一式战车炮的改型（约 930 辆），1943 年起换装战车第 14 联队，参加英帕尔战役。47mm 炮可击穿 55mm/500m，反坦克能力大幅提升。

**游戏行为**：
- 缓慢移动（speed = 25px/s），装甲更厚
- 每 4 秒发射一发 47mm 穿甲弹（直线，伤害 2，速度 300px/s，弹体更粗）
- HP 35，被击毁后大爆炸 + 必掉道具

#### 2.2.3 超轻型坦克（tankette）— 九七式轻装甲车 Te-Ke

**历史背景**：仅 4.7 吨的超轻型坦克（约 616 辆），中国/缅甸战场第 33/55/56 师团小战车中队装备。乘员仅 2 人，37mm 炮或机枪。

**游戏行为**：
- 快速移动（speed = 50px/s），成群出现（3~5 辆编队）
- 仅有机枪扫射（不发射炮弹），每 2 秒三连发（伤害 1×3，速度 200px/s）
- HP 12，薄装甲，容易被击毁但数量多

#### 2.2.4 军用卡车（supply_truck）— 九四式六轮卡车

**历史背景**：日军主力 6×6 卡车，飞虎队滇缅公路空袭的主要目标。1942 年 5 月陈纳德奉命轰炸滇缅公路日军运输队，炸毁大量卡车。

**游戏行为**：
- 从底部向上中速移动（speed = 40px/s），通常 3~5 辆编队
- 无攻击能力，但 HP 低（8），被击毁后**高概率掉落道具**（50% 掉 P/炸弹/分数）
- 编队全灭额外奖励 +2000 分

#### 2.2.5 自行火炮（assault_gun）— 一式炮战车 Ho-Ni I

**历史背景**：基于九七式中战车底盘加装 75mm 九十式野战炮，顶部敞开仅正面 50mm 防盾。1944 年战车第 14 联队炮战车中队实际装备。

**游戏行为**：
- 固定不动（阵地型），75mm 炮发射**大口径炮弹**
- 炮弹为抛物线轨迹（gravity 影响），落地产生 AOE 爆炸（半径 50px，伤害 3）
- 每 5 秒发射一发，HP 25

#### 2.2.6 野战火炮（field_gun）— 九零式 75mm 野战炮

**历史背景**：日军主力野战炮，广泛部署于中国战场阵地防御。

**游戏行为**：
- 固定不动，曲射弹幕
- 每 3 秒发射一发抛物线炮弹，落点为玩家当前位置前方 100px（预判射击）
- 炮弹落地有十字标记警告（0.5 秒前显示），然后爆炸
- HP 10

#### 2.2.7 装甲列车（armored_train）— 九四式装甲列车

**历史背景**：日军在华铁路沿线部署装甲列车护卫补给线，L06 宝庆补给中心以铁路为核心。

**游戏行为**：
- 沿铁轨水平移动（左右往返），不是从下往上
- 多炮塔设计：3 个炮塔独立射击（前/中/后），每个炮塔不同弹幕模式
  - 前炮塔：扇形散射（fan_shoot，5 发）
  - 中炮塔：瞄准射击（aimed_shoot，1 发高速弹）
  - 后炮塔：环形爆发（ring_burst，12 发）
- HP 60，击毁每个炮塔单独计分（200/300/200），主体击毁 800 分
- 类似 Boss 的多部件结构

#### 2.2.8 高射炮阵地（aa_battery）— 九六式 25mm 联装高射炮

**历史背景**：日军主力防空武器，L08 白螺矶机场和 L10 芷江机场防空核心。

**游戏行为**：
- 固定不动，高射速对空扫射
- 每 0.5 秒发射一组 3 发连射（追踪玩家 Y 坐标，带微扇形扩散）
- 子弹速度快（350px/s）但伤害低（1）
- HP 15，击毁后掉落炸弹道具概率高（40%）

### 2.5 MapObject 基类扩展

现有 `MapObject` 基类仅支持静态受击+滚动。新增地面单位需要**移动**和**射击**能力，需扩展基类：

```gdscript
# map_object.gd 新增导出属性

## v1.6: 移动速度（0=固定不动）
@export var move_speed: float = 0.0
## v1.6: 移动方向（"up"=从下往上, "left_right"=水平往返, "static"=固定）
@export var move_pattern: String = "static"
## v1.6: 射击间隔（秒，0=不射击）
@export var fire_interval: float = 0.0
## v1.6: 子弹场景
@export var bullet_scene: PackedScene = null
## v1.6: 子弹速度
@export var bullet_speed: float = 200.0
## v1.6: 子弹伤害
@export var bullet_damage: int = 1
## v1.6: 道具掉落概率
@export var drop_chance: float = 0.3
## v1.6: 可掉落的道具类型列表
@export var drop_types: Array[String] = ["power"]
```

```gdscript
# map_object.gd _process 扩展

func _process(delta: float) -> void:
    # 背景滚动
    if _scroll_speed > 0.0:
        position.y += _scroll_speed * delta
    # v1.6: 自主移动
    _update_movement(delta)
    # v1.6: 射击
    _update_firing(delta)

func _update_movement(delta: float) -> void:
    if move_pattern == "static" or move_speed <= 0.0:
        return
    match move_pattern:
        "up":
            position.y -= move_speed * delta  # 向上移动（对抗滚动）
        "left_right":
            _move_horizontal(delta)

var _h_direction: float = 1.0
var _h_range_min: float = 100.0
var _h_range_max: float = 980.0

func _move_horizontal(delta: float) -> void:
    position.x += _h_direction * move_speed * delta
    if position.x <= _h_range_min:
        _h_direction = 1.0
    elif position.x >= _h_range_max:
        _h_direction = -1.0

var _fire_timer: float = 0.0
func _update_firing(delta: float) -> void:
    if fire_interval <= 0.0 or bullet_scene == null:
        return
    _fire_timer += delta
    if _fire_timer >= fire_interval:
        _fire_timer = 0.0
        _fire_at_player()

func _fire_at_player() -> void:
    # 虚方法，子类覆盖实现不同射击模式
    pass
```

## 3. 舰船浪花尾迹 Shader

### 3.1 设计目的

海面/大江上的大型舰船（巡洋舰、驱逐舰、运输船）移动时，船尾应产生白色浪花尾迹，增强水上场景的真实感和运动感。

### 3.2 适用范围

| 关卡 | 水域 | 适用舰船 |
|------|------|---------|
| L02 仰光 | 仰光河 | 天龙号轻巡（Boss） |
| L04 新竹 | 台湾海峡 | 妙高号重巡（Boss）、巡逻艇 |
| L07 湘江 | 湘江航道 | 内河炮舰编队（Boss） |
| L08 白螺矶 | 长江 | 最上号重巡（Boss） |
| H2 广岛 | 太平洋 | （无舰船，仅 B-29） |

### 3.3 实现方案

浪花尾迹作为舰船 MapObject/Boss 的子节点，不依赖全局水面 Shader：

```
Ship (Area2D / BossBase)
├── Sprite2D (船体)
├── WakeTrail (CPUParticles2D)  ← v1.6 新增
│   ├── 尾部位置偏移 (0, 30)
│   ├── 方向：向下（相对船体，因为船在屏幕中近似静止，水面向下滚）
│   ├── 白色半透明粒子
│   └── 生命周期 1.5s，逐渐缩小+淡出
└── CollisionShape2D
```

**CPUParticles2D 参数**：

```gdscript
var wake: CPUParticles2D = CPUParticles2D.new()
wake.name = "WakeTrail"
wake.amount = 15
wake.lifetime = 1.5
wake.one_shot = false
wake.emitting = true
wake.local_coords = true
wake.position = Vector2(0, 30)  # 船尾偏移
wake.direction = Vector2(0, 1)  # 向下（水面滚动方向）
wake.spread = 15
wake.initial_velocity_min = 20
wake.initial_velocity_max = 40
wake.scale_amount_min = 0.8
wake.scale_amount_max = 1.5
wake.color = Color(0.9, 0.95, 1.0, 0.6)  # 白色半透明
wake.scale_curve = preload("res://resources/curves/wake_scale.tres")  # 先大后小
wake.color_ramp = preload("res://resources/curves/wake_alpha.tres")   # 先浓后淡
```

### 3.4 Boss 专用浪花

对于不可击沉的舰艇 Boss（天龙号/妙高号/最上号），浪花尾迹更明显：

```gdscript
# boss_base.gd 中新增
func _setup_ship_wake() -> void:
    if boss_type != "naval_assault":
        return
    var wake: CPUParticles2D = CPUParticles2D.new()
    wake.name = "ShipWake"
    wake.amount = 30           # Boss 尾迹更密集
    wake.lifetime = 2.0
    wake.position = Vector2(0, 50)  # 大型舰船尾部更远
    wake.direction = Vector2(0, 1)
    wake.spread = 20
    wake.initial_velocity_min = 30
    wake.initial_velocity_max = 60
    wake.color = Color(0.95, 0.98, 1.0, 0.7)
    # 添加到 Boss 的视觉根节点
    if visual_root:
        visual_root.add_child(wake)
    else:
        add_child(wake)
```

### 3.5 浪花与水面 Shader 的关系

- **水面 Shader**（`topdown_water.gdshader`）：全局水面流动效果，波动+泡沫，作用于 Parallax2D_Water 层
- **浪花尾迹**（CPUParticles2D）：附着在舰船上的局部粒子，模拟船体扰动水面的尾流
- 两者独立运作，不冲突：水面 Shader 提供底色流动，浪花粒子叠加白色尾流

## 4. H1 驼峰航线强风气流扰动

### 4.1 现状

H1 关卡已实现 `wind_force = Vector2(70, 0)` 持续侧风，通过 `player_node.external_force` 每帧施加恒定横向推力。

**问题**：恒定侧风仅是一个被动力，玩家只能感受到"飞机被推着走"，缺乏视觉提示和动态变化。需要补充：

1. **窜流/气旋视觉特效**：飞机周围出现扭曲的气流粒子，提示玩家有强风干扰
2. **阵风变化**：风力不是恒定的，而是周期性强弱变化（阵风）
3. **气旋区域**：特定位置出现局部气旋（涡流），经过时强烈偏移

### 4.2 气流扰动视觉特效

在玩家飞机周围生成气流粒子，风力越强粒子越密集：

```
Player (CharacterBody2D)

│   ├── 环绕飞机的半透明白色/灰色气流线
│   ├── 方向与 wind_force 一致
│   ├── 风力越强 amount 越多
│   └── 仅 H1 启用
└── ...
```

**CPUParticles2D 参数**：

### 4.3 阵风系统

将恒定风力改为周期性变化的阵风：

```gdscript
# level_base.gd 新增

## v1.6: 阵风参数（仅 H1 启用）
@export var gust_enabled: bool = false
## 阵风基础风力
@export var gust_base_force: float = 40.0
## 阵风最大增量
@export var gust_max_surge: float = 60.0
## 阵风周期（秒）
@export var gust_period: float = 4.0

var _gust_timer: float = 0.0

func _process(delta: float) -> void:
    # ... 现有逻辑 ...
    
    # v1.6: 阵风计算
    if gust_enabled and player_node != null and is_instance_valid(player_node):
        _gust_timer += delta
        # 正弦波模拟阵风强弱变化
        var gust_phase: float = sin(_gust_timer / gust_period * TAU)
        var current_force: float = gust_base_force + gust_max_surge * gust_phase
        player_node.external_force = Vector2(current_force, 0)
        
        # 更新气流粒子密度（风力越强粒子越多）
        _update_turbulence_intensity(current_force)
```

**气旋类型**：

| 类型 | 效果 | 视觉 |
|------|------|------|
| `vortex` (涡流) | 玩家进入区域时受旋转力偏移 | 螺旋状灰白色粒子 |
| `updraft` (上升气流) | 玩家被向上推 | 向上的白色气流线 |
| `downdraft` (下降气流) | 玩家被向下推 | 向下的灰色气流线 |
| `crosswind` (侧风增强) | 局部区域侧风加倍 | 水平条纹粒子 |

**气旋视觉实现**：

```gdscript
# 新建 scenes/effects/wind_zone.gd
class_name WindZone extends Node2D

@export var zone_type: String = "vortex"
@export var radius: float = 150.0
@export var force: float = 80.0
@export var direction: String = "clockwise"

var _particles: CPUParticles2D
var _player_ref: Node2D = null

func _ready() -> void:
    _setup_particles()
    _player_ref = get_tree().get_first_node_in_group("player")

func _process(delta: float) -> void:
    if _player_ref == null or not is_instance_valid(_player_ref):
        return
    var dist: float = global_position.distance_to(_player_ref.global_position)
    if dist <= radius:
        _apply_wind_force(delta, dist)

func _apply_wind_force(delta: float, dist: float) -> void:
    # 距离越近力越强
    var intensity: float = 1.0 - (dist / radius)
    match zone_type:
        "vortex":
            # 切向力（旋转）
            var tangent: Vector2 = (_player_ref.global_position - global_position).rotated(
                PI / 2.0 if direction == "clockwise" else -PI / 2.0
            ).normalized()
            _player_ref.external_force += tangent * force * intensity
        "updraft":
            _player_ref.external_force += Vector2(0, -force * intensity)
        "downdraft":
            _player_ref.external_force += Vector2(0, force * intensity)
        "crosswind":
            _player_ref.external_force += Vector2(force * intensity, 0)
```

### 4.5 H1 气流特效分层

```
H1 驼峰航线气流特效层级：
├── 持续侧风（阵风系统，gust_base=40, gust_max_surge=60）
│   └── 玩家周围 WindTurbulence 粒子（灰白色气流线）
├── 局部气旋区域（wind_zones，4~6 个）
│   ├── 涡流：螺旋粒子+旋转力

│   └── 下降气流：向下粒子+下推力
└── 背景雪花/冰晶（高海拔视觉，半透明白色粒子飘落）
```

### 4.6 玩家反馈机制

当玩家受到强风影响时，提供视觉/音效反馈：

1. **飞机倾斜加剧**：风力越强，`tilt_max_angle` 临时增大（从 15° 到 25°）
2. **屏幕边缘气流线**：强风时屏幕两侧出现水平气流条纹
3. **音效**：阵风周期性呼啸声（音量随风力变化）
4. **UI 提示**：首次进入气旋区域时显示 "湍流警报" 文字
