## 1. H1 驼峰航线 — 零式战机拦截修正

### 1.1 历史背景

驼峰航线（1942–1945）是盟军从印度飞越喜马拉雅向中国运输物资的空中走廊。**日军在缅甸密支那（Myitkyina）和八莫机场驻有零式战斗机联队，专门拦截无武装、速度慢的 C-46/C-87 运输机**，日军飞行员称之为"辻斬"（Tsujigiri，武士斩杀路人之意）[$TRAE_REF](https://infogalactic.com/info/The_Hump)。

零式战斗机时速约580公里，升限7000米以上，对运输机形成绝对优势[$TRAE_REF](http://www.china918.org/news/read?id=1372)。1943年上半年仅驼峰航线就有近百架运输机损失，航线东段成为"死亡空域"[$TRAE_REF](http://m.toutiao.com/group/7652203103973835306/)。1943年10月20、23、27日连续拦截击落5架以上 C-46[$TRAE_REF](https://infogalactic.com/info/The_Hump)。

**转折点**：1944年5月17日，梅里尔突击队（Merrill's Marauders）经20天丛林行军突袭密支那机场[$TRAE_REF](http://www.14usaaf27tcs.4mg.com/myitkyina.htm)。**密支那解放后，驼峰航线上再无零式踪迹**[$TRAE_REF](http://m.toutiao.com/group/7212626790085853699/)。

同时期日军陆军航空队的 Ki-43 隼（Oscar）也承担了大量缅甸/中国战场的制空任务[$TRAE_REF](https://api.pageplace.de/preview/DT0400.9781849087032_A24195581/preview-9781849087032_A24195581.pdf)。

### 1.2 当前设计错误

当前 `stage_H1_hump_extreme.csv` 注释写道：
```
# 驼峰航线历史很少有日本飞机拦截，本关重点为快速滚动+强风+地形障碍躲避
# skip_enemy_spawning=true，普通敌机波次被跳过
```

**这与历史事实相反**。v1.5 删除 `a6m_zero` 的理由是"历史不准确"，但实际上零式拦截驼峰航线是真实历史。需修正此设计，恢复零式拦截波次。

### 1.3 零式战机速度澄清

用户问"零式飞机是飞行比较快速的那种是吧"——需澄清：

| 机型 | 最大速度 | 特点 |
|------|---------|------|
| A6M 零战 | ~533–565 km/h | **机动性+航程**著称，非纯速度型 |
| Ki-43 隼(Oscar) | ~530–560 km/h | 陆军主力，机动性优秀 |
| Ki-44 钟馗(Shoki) | ~605 km/h | **高速爬升截击**，速度最快 |
| J2M 雷电 | ~595 km/h | 局地截击机，爬升快 |

零战的真正优势是**盘旋机动性和超长航程**（护卫轰炸机深入），而非绝对速度。但作为游戏中的拦截者，零战的高速猎杀运输机场景是成立的——它比 C-46 运输机（~350 km/h）快得多。

### 1.4 H1 敌机波次重新设计

**设计意图**：H1 为"护送+环境关"，玩家保护 C-47 运输机编队穿越驼峰。零式战机从后方/侧方高速俯冲突袭运输机，玩家需拦截保护。这比纯环境躲避更有历史代入感和游戏张力。

**H1 波次设计原则**：
- 零式战机以**小编队（2~3架）高速俯冲**出现，模拟猎杀运输机
- Ki-43 隼作为辅助拦截机，水平横穿干扰
- 波次间隔比普通关卡稀疏（环境障碍+强风仍是主难度）
- 护送的 C-47 运输机作为保护目标，零式会优先攻击运输机

### 2.3 新增实验机型设计

#### 2.3.1 秋水 J8M（火箭截击机）— 新增

**历史原型**：三菱 J8M 秋水，基于德国 Me 163 Komet 火箭动力截击机仿制。搭载 KR10 火箭发动机（1500kg推力），设计时速900km/h，实用升限12000米，武装2门30mm Ho-155机炮。**仅5分30秒动力飞行时间**。1945年7月试飞中坠毁，未服役[$TRAE_REF](https://www.historyofwar.org/articles/weapons_mitsubishi_J8M_Ki-200.html)[$TRAE_REF](https://planesoffame.org/aircraft/plane-J8M1)。

**游戏定位**：**极速冲刺型精英敌机**，出场时间极短但压迫感极强。模拟火箭动力的"一击脱离"战术。

| 参数 | 值 | 说明 |
|------|-----|------|
| hp | 6 | 精英级 |
| speed | 280.0 | **全游戏最快敌机**（普通敌机~120-180） |
| score_value | 800 | 高分奖励 |
| drop_chance | 0.5 | 高掉落 |
| 出场时间 | 2.5秒 | 极短，冲刺后离场 |
| bullet_pattern | aimed_shoot | 2发30mm高速弹（伤害2） |
| 移动路径 | rocket_dive | 新路径：直线高速冲刺，不回旋 |

**特殊机制**：秋水出场时从屏幕顶部垂直高速冲下，2.5秒后冲出屏幕底部。期间发射2发30mm炮弹。玩家若未及时击落，秋水会冲过屏幕消失（模拟燃料耗尽）。出场时尾部留蓝色火焰尾迹（CPUParticles2D）。

**核心代码逻辑**:
```gdscript
class_name EnemyJ8mShusui extends EnemyBase

## 燃料持续时间（秒），到时自动离场
@export var fuel_duration: float = 2.5
var _fuel_timer: float = 0.0

func _process(delta: float) -> void:
    super._process(delta)
    _fuel_timer += delta
    if _fuel_timer >= fuel_duration:
        # 燃料耗尽，加速冲出屏幕
        speed *= 1.5
        # 不再射击
        set_meta("no_fire", true)

func _ready() -> void:
    super._ready()
    _setup_rocket_trail()

func _setup_rocket_trail() -> void:
    var trail: CPUParticles2D = CPUParticles2D.new()
```
