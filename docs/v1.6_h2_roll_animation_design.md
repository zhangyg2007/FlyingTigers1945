## 1. 翻滚动画技术方案

> **重要更正**：v1 初稿误将翻滚理解为"上下翻斗"（绕 X 轴，scale.y 缩放）。
> 实际需求为**滚筒翻滚**（绕机身长轴/Y轴旋转，飞机像桶一样左右滚）。
> 以下为修正后的方案。

### 1.1 滚筒翻滚 vs 上下翻斗

| | 上下翻斗（错误方案） | 滚筒翻滚（正确方案） |
|---|---|---|
| 旋转轴 | X 轴（左右水平轴） | **机身长轴**（飞行方向轴） |
| 实现 | scale.y = cos(θ) | **scale.x = cos(θ) + 三图切换** |
| 视觉 | 机头上下俯仰，变胖变瘦 | 机翼左右翻滚，俯视→侧视→仰视 |
| 需要的图 | 1 张俯视 | **俯视 + 仰视 + 侧视**（3张） |

### 1.2 方案对比

| 方案 | 原理 | 素材需求 | 效果 | 适用场景 |
|------|------|---------|------|---------|
| **三图切换滚筒** (推荐) | scale.x=cos(θ) + 俯/侧/仰三图切换 | 3张/机型 | 连续滚筒，侧面有细节 | 杂兵+Boss |
| 双图滚筒 | scale.x=cos(θ) + 俯/仰双图切换 | 2张/机型 | 侧视为竖线，无细节 | 简化版 |
| 单图假滚筒 | scale.x=cos(θ)，180°翻转俯视图 | 1张/机型 | 仰视用翻转俯视代替 | 最低成本 |
| 八方向精灵拼接 | 8张离散朝向贴图 | 8张/机型 | 阶梯跳变 | 已淘汰 |
| 帧动画序列 | 16+帧预渲染 | 16+张/机型 | 最流畅 | 需3D渲染 |

**选定方案**：三图切换滚筒。需3张图（俯视+侧视+仰视），通过 `scale.x = cos(θ)` 控制宽度缩放 + 按角度区间切换显示哪张图，实现连续360°滚筒翻滚。

### 1.3 核心原理：三图切换 + scale.x 缩放

```
roll_angle:  0°    45°    90°    135°   180°   225°   270°   315°   360°
cos(θ):     +1.0   +0.71  ≈0    -0.71  -1.0   -0.71   ≈0    +0.71  +1.0
scale.x:     1.0    0.71  ≈0.1   0.71   1.0    0.71   ≈0.1   0.71   1.0
显示图:      俯视   俯视   侧视   仰视   仰视   仰视   侧视   俯视   俯视
```

- `cos(θ) > +阈值`：显示**俯视图**，`scale.x = cos(θ)`（翼展缩窄）
- `|cos(θ)| ≤ 阈值`（约81°~99°）：显示**侧视图**（机翼朝镜头，显示机身侧面轮廓）
- `cos(θ) < -阈值`：显示**仰视图**，`scale.x = |cos(θ)|`（机腹翼展缩窄）
- 阈值默认 0.15（约9°宽的侧视区间），可根据视觉效果调整

### 1.4 核心代码

```gdscript
## 滚筒翻滚：三图切换 + scale.x = cos(θ)
## 需要场景中有三个 Sprite2D 子节点：SpriteTop / SpriteSide / SpriteBottom

@export var roll_speed: float = 540.0  ## 度/秒
@export var side_threshold: float = 0.15  ## 侧视切换阈值（|cos|≤此值时显示侧视）

var _roll_angle: float = 0.0
@onready var sprite_top: Sprite2D = $SpriteTop
@onready var sprite_side: Sprite2D = $SpriteSide
@onready var sprite_bottom: Sprite2D = $SpriteBottom

func _process(delta: float) -> void:
    super._process(delta)
    # 持续滚筒旋转
    _roll_angle += roll_speed * delta
    var c: float = cos(deg_to_rad(_roll_angle))
    var abs_c: float = abs(c)

    if abs_c > side_threshold:
        # 显示俯视或仰视
        var is_top: bool = c > 0
        sprite_top.visible = is_top
        sprite_bottom.visible = not is_top
        sprite_side.visible = false
        # 宽度跟随余弦缩放
        if is_top:
            sprite_top.scale.x = abs_c
        else:
            sprite_bottom.scale.x = abs_c
    else:
        # 侧视区间：机翼朝向镜头，显示机身侧面
        sprite_top.visible = false
        sprite_bottom.visible = false
        sprite_side.visible = true
```

### 1.5 Curve2D 路径方案（Ki-21 等曲线飞行）

记录两种方案，当前选用 Curve2D：

**方案A（当前采用）：Curve2D 切线采样**

```gdscript
## enemy_base.gd 改造
@export var move_path: Curve2D = null  ## 类型从 Resource 改为 Curve2D

func _move_along_path(delta: float) -> void:
    if move_path == null:
        return
    _path_progress += speed * delta
    var total: float = move_path.get_baked_length()
    if _path_progress >= total:
        if loop_path:
            _path_progress -= total
        else:
            _path_progress = total

    # 1. 采样位置
    global_position = curve.sample_baked(_path_progress)
    # 2. 采样切线 → 平滑旋转（精灵朝向跟随曲线）
    var tangent: Vector2 = curve.sample_baked_tangent(_path_progress)
    if tangent.length_squared() > 0.001:
        rotation = tangent.angle() - PI / 2.0  # 精灵默认朝下的偏移
```

> **注意**：Curve2D 的 `rotation` 控制的是飞机航向（机头朝哪飞），
> 与滚筒翻滚的 `_roll_angle`（绕机身轴自旋）是**两个独立维度**，互不冲突。
> 飞机可以一边沿曲线转弯（rotation 跟随切线），一边持续滚筒翻滚（scale.x 三图切换）。

**方案B（备选）：PathFollow2D 节点**

场景中添加 `Path2D → PathFollow2D → EnemySprite`，设置 `path_follow.rotates = true`，推进 `path_follow.progress += speed * delta`。位置和旋转全自动，但需改场景树结构，对 SpawnManager 改动较大。

### 1.6 滚筒翻滚 + 螺旋路径组合（杂兵级）

杂兵（秋水/震电）的"螺旋曲线冲过来"= **正弦波 Curve2D 路径** + **滚筒翻滚动画**同步：

```
路径形状（俯视）：  →  ～～～～～～  →
                    正弦波横向摆动（控制位置+航向）

翻滚动画：          scale.x = cos(roll_speed * t) + 三图切换
                    与路径推进同步，持续滚筒自旋
```

**Curve2D 路径数据**（螺旋俯冲，左切入为例）：
- 起点：屏幕左侧外 (x=-50, y=100)
- 正弦波横向摆动：3个完整波周期，振幅80px
- 终点：屏幕底部 (x=300, y=900)
- 路径长度约 1200px，speed=160 → 约7.5秒飞越屏幕

**滚筒翻滚参数**：
- `roll_speed = 540°/s`（1.5秒翻一圈，视觉上有压迫感但不过快）
- 翻滚方向与飞行方向一致（右切入顺时针，左切入逆时针）
- `side_threshold = 0.15`（侧视区间约9°宽）

## 3. Boss级双机编队设计（震电改 红色 + 黑色）

### 3.1 设计概述

当前 `boss_shinden_kai.tscn` 为单机 Boss（HP 12000）。改为**双机编队**，一前一后，各自独立行动：

| Boss | 涂装 | 位置 | 弹幕特色 | 移动方式 |
|------|------|------|---------|---------|
| **震电改·赤** | 红色+黑色条纹 | 玩家前方 | 空中气球/地雷障碍物投放 | 横向翻滚移动 |
| **震电改·玄** | 纯黑色+红色细节 | 玩家后方 | 三岔路火线射击 | 横向翻滚移动 |

**编队逻辑**：
- 赤机始终保持在玩家**前方**（y < player.y），横向左右移动并翻滚，投放障碍物阻挡玩家前进路线
- 玄机始终保持在玩家**后方**（y > player.y），横向左右移动并翻滚，发射三岔火线从后方追击
- 两机 Y 坐标差约 200-300px，形成前后夹击
- 两机 X 坐标独立运动，偶尔交叉，增加弹幕覆盖面

### 3.4 双机编队管理

**新增脚本**：`scenes/bosses/boss_shinden_kai_dual.gd`

```gdscript
class_name BossShindenKaiDual extends BossBase

## 双Boss编队管理器：同时控制赤机和玄机

@export var red_boss_config: String = "res://resources/boss_data/boss_shinden_kai_red.json"
@export var black_boss_config: String = "res://resources/boss_data/boss_shinden_kai_black.json"

var _red_boss: BossBase = null
var _black_boss: BossBase = null
var _player: Node2D = null

func _ready() -> void:
    super._ready()
    _player = get_tree().get_first_node_in_group("player")
    _spawn_dual_bosses()

func _spawn_dual_bosses() -> void:
    # 赤机：玩家前方
    _red_boss = _create_boss("red", red_boss_config)
    # 玄机：玩家后方
    _black_boss = _create_boss("black", black_boss_config)

func _process(delta: float) -> void:
    # 同步两机Y坐标跟随玩家
    if _player and is_instance_valid(_player):
        var player_y: float = _player.global_position.y
        if _red_boss and is_instance_valid(_red_boss):
            _red_boss.target_y = player_y - 200
            _update_horizontal_sweep(_red_boss, delta, "red")
            _update_roll(_red_boss, delta)
        if _black_boss and is_instance_valid(_black_boss):
            _black_boss.target_y = player_y + 200
            _update_horizontal_sweep(_black_boss, delta, "black")
            _update_roll(_black_boss, delta)

    # 检查双机是否全部死亡
    var red_alive: bool = _red_boss and is_instance_valid(_red_boss) and not _red_boss.is_dead
    var black_alive: bool = _black_boss and is_instance_valid(_black_boss) and not _black_boss.is_dead
    if not red_alive and not black_alive:
        _on_dual_boss_defeated()

## 横向左右扫描移动
var _sweep_time: Dictionary = {"red": 0.0, "black": 0.0}
func _update_horizontal_sweep(boss: BossBase, delta: float, key: String) -> void:
    _sweep_time[key] += delta
    var period: float = 4.0 if key == "red" else 4.5
    var x_range: Array = [80, 520]
    var t: float = sin(_sweep_time[key] * TAU / period)
    boss.global_position.x = (x_range[0] + x_range[1]) / 2.0 + t * (x_range[1] - x_range[0]) / 2.0

## 滚筒翻滚动画（三图切换）
var _roll_angle: Dictionary = {"red": 0.0, "black": 0.0}
const SIDE_THRESHOLD: float = 0.15

func _update_roll(boss: BossBase, delta: float) -> void:
    var key: String = "red" if boss == _red_boss else "black"
    var roll_speed: float = 300.0 if key == "red" else 280.0
    _roll_angle[key] += roll_speed * delta
    var c: float = cos(deg_to_rad(_roll_angle[key]))
    var abs_c: float = abs(c)
    # Boss 场景需有 SpriteTop / SpriteSide / SpriteBottom 三个子节点
    var sprite_top: Sprite2D = boss.get_node_or_null("SpriteTop")
    var sprite_side: Sprite2D = boss.get_node_or_null("SpriteSide")
    var sprite_bottom: Sprite2D = boss.get_node_or_null("SpriteBottom")
    if sprite_top == null or sprite_bottom == null or sprite_side == null:
        return  # 节点缺失，跳过翻滚
    if abs_c > SIDE_THRESHOLD:
        var is_top: bool = c > 0
        sprite_top.visible = is_top
        sprite_bottom.visible = not is_top
        sprite_side.visible = false
        if is_top:
            sprite_top.scale.x = abs_c
        else:
            sprite_bottom.scale.x = abs_c
    else:
        sprite_top.visible = false
        sprite_bottom.visible = false
        sprite_side.visible = true
```

```gdscript
## 滚筒翻滚：三图切换 + scale.x = cos(θ)
@export var roll_speed: float = 540.0  # 震电；秋水=720.0
@export var side_threshold: float = 0.15  # 秋水=0.12

var _roll_angle: float = 0.0
@onready var sprite_top: Sprite2D = $SpriteTop
@onready var sprite_side: Sprite2D = $SpriteSide
@onready var sprite_bottom: Sprite2D = $SpriteBottom

func _process(delta: float) -> void:
    super._process(delta)
    _roll_angle += roll_speed * delta
    var c: float = cos(deg_to_rad(_roll_angle))
    var abs_c: float = abs(c)
    if abs_c > side_threshold:
        var is_top: bool = c > 0
        sprite_top.visible = is_top
        sprite_bottom.visible = not is_top
        sprite_side.visible = false
        if is_top:
            sprite_top.scale.x = abs_c
        else:
            sprite_bottom.scale.x = abs_c
    else:
        sprite_top.visible = false
        sprite_bottom.visible = false
        sprite_side.visible = true
```

```gdscript
## 三岔路火线：中间瞄准玩家，两侧各偏spread_angle度
func _fire_trident(spread_angle: float, bullet_speed: float, damage: int) -> void:
    if bullet_scene == null or _player == null:
        return
    var to_player: Vector2 = (_player.global_position - global_position).normalized()
    var base_angle: float = to_player.angle()
    for i in range(-1, 2):  # -1, 0, 1
        var angle: float = base_angle + i * deg_to_rad(spread_angle)
        var bullet: BulletBase = bullet_scene.instantiate()
        bullet.global_position = global_position
        bullet.is_player_bullet = false
        bullet.direction = Vector2.from_angle(angle)
        bullet.speed = bullet_speed
        bullet.damage = damage
        get_parent().add_child(bullet)
```

**验收标准**：
- [ ] 三发子弹呈扇形射出，中间精准瞄准玩家
