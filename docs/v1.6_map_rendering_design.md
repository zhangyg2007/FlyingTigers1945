# Flying Tigers 1945 — v1.6 地图渲染系统设计文档

> **版本**: v1.6.0  
> **日期**: 2026-07-29  
> **状态**: 待Code Agent实施  
> **风格目标**: 《iFighter 2: The Pacific 1942》级别的高清2D数字拼贴（HD 2D Photobashing）  
> **引擎**: Godot 4.7（支持Parallax2D / canvas_item Shader / NormalMap）

---

## 一、设计目标与核心原则

### 1.1 视觉目标

参考《iFighter 2》的视觉核心：**高分辨率写实贴图 + 多层视差滚动 + 引擎2D动态Shader**，在不建模、不做像素画的前提下达到高清2D STG效果。

### 1.2 三大核心原则

1. **地表循环 + 地标不循环**：无缝地表贴图（2048×2048）用Parallax2D的`repeat_size`无限循环铺底色；地标建筑（机库、民居、桥梁等）作为独立PNG挂在Parallax2D子节点，位置固定，随滚动一去不返——解决"巫家坝机场重复出现"问题。

2. **分段切换非无限循环**：每关按时长拆为2~4段，段间用已有的`change_bg_layer()`切换。每段内地表循环、地标不循环，段间完全更换地表贴图+地标集。

3. **水面用Shader动态渲染**：河流/湖泊/海面挂载`topdown_water.gdshader`，通过Noise纹理扰动UV实现流动效果，无需逐帧绘制。

### 1.3 与v1.5方案的差异

| 维度 | v1.5方案 | v1.6方案 | 变更原因 |
|------|----------|----------|----------|
| 背景节点 | ParallaxBackground + ParallaxLayer | Parallax2D | 旧节点无autoscroll/repeat内置功能，滚动公式有bug |
| 地图尺寸 | 800×2400单张 | 1080×4800分段（2~4段/关） | 800px有黑边；2400px不够120~180s时长 |
| 地图制作 | 整张手绘 | 无缝贴图+地标PNG拼贴 | 整张手绘无法复用、修改困难、外包不友好 |
| 循环方式 | motion_mirroring无限循环 | 地表repeat循环+地标不循环+段间切换 | 地标重复不合理 |
| 水面 | 静态贴图 | topdown_water.gdshader动态 | iFighter 2级别需要动态水面 |
| 分辨率 | 800px宽 | 1080px宽（满屏） | 屏幕为1080×1920 |
| 滚动公式 | `offset += speed * delta * mirroring * 0.01`（bug） | Parallax2D内置autoscroll | 旧公式实际速度=预期×20 |

## 三、技术架构

### 3.1 场景节点树（新）

```text
LevelRoot (Node2D)  ← level_base.gd 挂载
├── Camera2D (Position: 540, 960)
├── Parallax2D_Clouds                    ← 云层（全程循环）
│   ├── Sprite2D (cloud_01.png, 半透明)
│   ├── Sprite2D (cloud_02.png, 半透明)
│   └── Sprite2D (cloud_03.png, 半透明)
│   autoscroll = Vector2(0, scroll_speed * 1.3)
│   repeat_size = Vector2(0, 1920)
│   repeat_times = 3
│
├── Parallax2D_Ground                    ← 地表+地标层（核心层）
│   ├── Sprite2D (地表无缝贴图, region_enabled=true)
│   │   ← repeat_size = Vector2(0, 1920) 实现底色循环
│   ├── Sprite2D (地标PNG_01, position=Y_01)  ← 不循环
│   ├── Sprite2D (地标PNG_02, position=Y_02)
│   └── ... (更多地标)
│   autoscroll = Vector2(0, scroll_speed)
│   repeat_size = Vector2(0, 1920)  ← 仅影响地表Sprite
│
├── Parallax2D_Water (条件层)            ← 仅水面区域启用
│   └── Sprite2D (tex_water_base.png)
│       material = ShaderMaterial (topdown_water.gdshader)
│   autoscroll = Vector2(0, scroll_speed)
│   visible = false (默认隐藏，水面区域设true)
│
├── GameplayLayer (Node2D)               ← 游戏核心层
│   ├── Player
│   ├── Enemies / Bullets
│   └── MapObjects (由MapObjectManager动态生成)
│
└── UI / CanvasLayer
```

### 3.2 Parallax2D vs 旧ParallaxLayer对比

| 特性 | 旧 ParallaxLayer | 新 Parallax2D | 影响 |
|------|-----------------|---------------|------|
| 自动滚动 | 需手写motion_offset代码 | 内置`autoscroll`属性 | 删除`_update_bg_scroll`中的手写滚动 |
| 无缝重复 | `motion_mirroring` | `repeat_size` + `repeat_times` | 更精确控制 |
| 视差缩放 | `motion_scale` | `scroll_scale` | 属性名变更 |
| 挂载位置 | 必须在ParallaxBackground下 | 可挂在任意Node2D下 | 更灵活 |
| 滚动bug | `offset += speed * mirroring * 0.01` | 内置autoscroll无此问题 | 修复速度错误 |

### 3.3 分段切换机制

利用已有的`change_bg_layer()`函数，但需要扩展为同时切换地表贴图和地标集：

```gdscript
# level_base.gd 新增方法
## 切换地图段（地表贴图 + 地标集 + 水面配置）
## [param segment_index]: 段索引（0-based）
## [param ground_texture]: 新地表无缝贴图路径
## [param landmark_scene]: 新地标集场景（含所有地标Sprite2D）
## [param water_config]: 水面Shader配置（可选）
func change_map_segment(segment_index: int, ground_texture_path: String, 
                        landmark_scene: PackedScene, water_config: Dictionary = {}) -> void:
    # 1. 替换地表贴图
    var ground_layer = bg_layers[1]  # Parallax2D_Ground
    var ground_sprite = ground_layer.get_child(0) as Sprite2D
    ground_sprite.texture = load(ground_texture_path)
    
    # 2. 清除旧地标，加载新地标
    for i in range(1, ground_layer.get_child_count()):
        ground_layer.get_child(i).queue_free()
    var landmarks = landmark_scene.instantiate()
    for child in landmarks.get_children():
        ground_layer.add_child(child)
    
    # 3. 更新水面Shader配置
    if water_config.size() > 0:
        var water_layer = bg_layers[2]  # Parallax2D_Water
        water_layer.visible = water_config.get("visible", false)
        if water_layer.visible:
            var water_sprite = water_layer.get_child(0) as Sprite2D
            var mat = water_sprite.material as ShaderMaterial
            mat.set_shader_parameter("flow_speed", water_config.get("flow_speed", 0.15))
            mat.set_shader_parameter("water_tint", water_config.get("water_tint", Color(0.12, 0.35, 0.55)))
    
    # 4. 重置滚动偏移（新段从0开始）
    bg_scroll_offset_y = 0.0
    
    # 5. 清空并重新加载MapObject
    if MapObjectManager:
        MapObjectManager.clear()
        # 加载新段的map JSON...
    
    print("[LevelBase] 切换到地图段 %d" % segment_index)
```

### 3.4 分段切换时间表（每关）

在`level_base.gd`的`_process`中检查切换时间点：

```gdscript
# 每关的分段切换时间表（从stage_config.json读取）
var _segment_switch_times: Array[float] = []  # 如 [60.0] 或 [50.0, 100.0]
var _current_segment: int = 0
var _segment_scenes: Array[PackedScene] = []  # 每段的地标集场景

func _process(delta):
    # ... 现有逻辑 ...
    
    # 检查段切换
    if _current_segment < _segment_switch_times.size():
        if level_timer >= _segment_switch_times[_current_segment]:
            _current_segment += 1
            _switch_to_segment(_current_segment)
```

## 五、Code Agent任务分配

### 任务M1：Parallax2D架构迁移（P0）

**目标**：将背景系统从ParallaxBackground+ParallaxLayer迁移到Parallax2D

**修改文件**：
- `levels/level_base.gd`：重写`_create_parallax_background()`和`_update_bg_scroll()`
- 所有`scenes/backgrounds/bg_*_placeholder.tscn`：从ParallaxLayer改为Parallax2D

**具体要求**：

1. `_create_parallax_background()`改为创建3个Parallax2D节点（云层/地表/水面），不再用ParallaxBackground包装。每个Parallax2D设置：
   - `autoscroll = Vector2(0, bg_scroll_speed * 层倍率)`
   - `repeat_size = Vector2(0, 1920)`
   - `repeat_times = 3`
   - 云层倍率=1.3，地表倍率=1.0，水面倍率=1.0

2. `_update_bg_scroll(delta)`简化为仅记录`bg_scroll_offset_y += bg_scroll_speed * delta`（供MapObjectManager使用），不再手动移动layer。

3. 保留`change_bg_layer()`函数但适配Parallax2D。

4. 新增`_setup_water_shader()`方法，给水面Parallax2D的Sprite2D挂载`topdown_water.gdshader`。

**验收标准**：
- 游戏运行后背景自动滚动，速度正确（不再有20倍bug）
- 云层比地表快1.3倍
- `bg_scroll_offset_y`数值正确递增
- MapObjectManager的生成窗口判断不受影响

## 七、风险与注意事项

### 7.1 段切换的视觉过渡

段切换瞬间替换地表贴图可能有闪烁。**缓解方案**：
- 切换点选在水面→陆地或地形自然过渡处
- 可在切换时加0.5秒的淡入淡出动画（可选，MVP阶段可跳过）
- 地表贴图的颜色基调尽量接近（如红土→草地都是暖色调）

### 7.2 MapObject坐标系重置

段切换时`bg_scroll_offset_y`重置为0，MapObjectManager的`_pending_objects`也需重新加载。**注意**：
- 旧段未生成的pending对象会被丢弃（正常，因为玩家已飞过）
- 新段的map JSON中`map_spawn_y`从0开始
- 已生成的活跃对象（`_active_objects`）在clear()时归还对象池

### 7.3 内存管理

每段4800px×1080px的地标集场景不会同时加载（切换时释放旧段）。地表贴图2048×2048×8张约16MB，可全部预加载。地标PNG每张<100KB，单段约20张<2MB。

### 7.4 H1驼峰特殊处理

H1的山壁障碍需要碰撞体，不能仅用背景Sprite。山壁作为MapObject/Obstacle生成，与背景的山体贴图视觉对齐。这需要Design制作山壁贴图时标注碰撞体轮廓。

## 附录B：水面Shader完整代码

```glsl
shader_type canvas_item;

uniform vec4 water_tint : source_color = vec4(0.12, 0.35, 0.55, 1.0);
uniform vec4 foam_color : source_color = vec4(0.85, 0.95, 1.0, 0.5);
uniform sampler2D noise_texture : repeat_enable, filter_linear;
uniform vec2 flow_direction = vec2(0.0, 1.0);
uniform float flow_speed : hint_range(0.0, 2.0) = 0.15;
uniform float distortion_strength : hint_range(0.0, 0.1) = 0.025;
uniform float wave_frequency : hint_range(1.0, 30.0) = 12.0;

void fragment() {
    vec2 moving_uv = UV + flow_direction * TIME * flow_speed;
    vec4 noise = texture(noise_texture, moving_uv);
    vec2 distortion = (noise.rg - vec2(0.5)) * distortion_strength;
    vec2 distorted_uv = UV + distortion;
    vec4 tex_color = texture(TEXTURE, distorted_uv);
    float wave = sin((distorted_uv.y + distorted_uv.x) * wave_frequency + TIME * 2.0);
    float foam = smoothstep(0.75, 0.95, wave * noise.r);
    vec3 final_rgb = mix(tex_color.rgb * water_tint.rgb, foam_color.rgb, foam * foam_color.a);
    COLOR = vec4(final_rgb, tex_color.a * water_tint.a);
}
```
