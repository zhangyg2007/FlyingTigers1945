# Flying Tigers 1945 — v1.6 武器系统与弹幕升级设计文档

> **版本**: v1.6 Weapon & Bullet Pattern Design v1.0
> **日期**: 2026-07-29
> **基准**: v1.5 完成状态（F1-F6 全部交付，testlog.md 记录通过）
> **核心目标**: 将 P-40 真实历史武器系统街机化、将日军弹幕模式从通用几何弹升级为带文化符号和历史战术代入感的特色弹幕

---

## 1. 设计哲学

v1.6 的核心原则是 **"历史武装街机化，弹幕性格化"**：

1. **主武器演进史**：P-40 从早期型（机鼻2挺+机翼4挺轻机枪）到后期型（机翼6挺重机枪）的火力演进，映射为 4 级火力升级树
2. **副武器战术化**：三种副武器对应飞虎队三种真实战术（火箭弹对舰/僚机编队/凝固汽油对地），通过彩色道具切换
3. **大招选择制**：关卡开始前选择大招类型，陈纳德战术（清屏杂兵）vs 500磅定点轰炸（Boss核心爆破）
4. **被动差异化**：P-40 重装甲特性转化为"擦弹不死亡"机制，与日军轻战机形成对比
5. **敌弹符号化**：日军弹幕融入旭日/落樱/居合斩/神风等文化符号，红粉冷色调与 P-40 黄橙暖色调形成视觉对立

## 2. 现状分析

### 2.1 当前主武器实现（player_base.gd）

| 等级 | 当前实现 | 问题 |
|------|---------|------|
| Lv.1 | 单发直线弹（1颗） | 缺少双联装机枪的历史感 |
| Lv.2 | 双发平行弹（2颗） | 缺少翼载机枪的发散角度 |
| Lv.3 | 三发微扇形（1直+2斜） | 与历史六挺重机枪不符 |
| Lv.4 | 四发宽扇形（4颗） | 无穿透效果，无视觉差异 |

**核心问题**：
- 子弹颜色统一无差异化（无法区分火力等级）
- 无穿透机制（Lv.Max 需要 AP-IT 穿甲燃烧弹）
- 子弹无尾迹特效
- `bullet_damage` 固定为 1，不随等级提升

### 2.2 当前副武器实现

**无副武器系统**。当前只有 `PowerupType` 枚举（POWER/BOMB/SCORE/MEDKIT），无 M/W/B 副武器切换机制。

### 2.3 当前大招系统

单一炸弹模式：全屏清弹 + 对所有敌机造成5点伤害 + 2秒无敌。无大招选择机制，无差异化演出。

### 2.4 当前被动机制

判定点（Hitbox）半径 4px，碰撞即损命。无"擦弹"机制，机翼碰弹即死。

### 2.5 当前敌弹模式（boss_base.gd）

| 模式名 | 实现 | 问题 |
|--------|------|------|
| fan_shoot | 扇形散射 | 通用，无日军特色 |
| turret_fire | 定点轮射 | 通用，无文化符号 |
| missile_volley | 导弹齐射 | 通用 |
| spiral_shoot | 单螺旋 | 缺少双螺旋，无旋转视觉差异 |
| aimed_shoot | 瞄准射击 | 无警告线，无"居合斩"瞬杀感 |

### 4.4 副武器发射逻辑

在 `_physics_process` 中新增 `_update_sub_weapon(delta)`：

```gdscript
func _update_sub_weapon(delta: float) -> void:
    match current_sub_weapon:
        SubWeaponType.ROCKETS:
            _sub_weapon_timer += delta
            if _sub_weapon_timer >= 2.0:
                _sub_weapon_timer = 0.0
                _fire_rockets()
        SubWeaponType.WINGMEN:
            # 僚机由独立节点管理跟随，这里只处理持续时间
            _wingmen_timer -= delta
            if _wingmen_timer <= 0:
                _dismiss_wingmen()
        SubWeaponType.BOMBLETS:
            _sub_weapon_timer += delta
            if _sub_weapon_timer >= 1.5:
                _sub_weapon_timer = 0.0
                _fire_bomblets()
```

### 4.5 僚机系统（Wingmen）

僚机为独立 Node2D 节点，跟随主机移动并向前开火：

```gdscript
func _spawn_wingmen() -> void:
    _dismiss_wingmen()  # 先清理旧僚机
    for i in range(2):
        var wingman: Node2D = _wingman_scene.instantiate()
        var offset_x: float = -40.0 if i == 0 else 40.0
        wingman.global_position = global_position + Vector2(offset_x, 20)
        get_parent().add_child(wingman)
        wingman.set_meta("offset", Vector2(offset_x, 20))
        wingman.set_meta("hp", 3)  # 可挡3发流弹
        _wingmen.append(wingman)
    _wingmen_timer = 30.0  # 持续30秒

func _update_wingmen_position(delta: float) -> void:
    for wingman in _wingmen:
        if not is_instance_valid(wingman):
            continue
        var offset: Vector2 = wingman.get_meta("offset", Vector2.ZERO)
        var target_pos: Vector2 = global_position + offset
        # 平滑跟随
        wingman.global_position = wingman.global_position.lerp(target_pos, 5.0 * delta)
        # 僚机自动开火
        if wingman.has_method("fire"):
            wingman.fire()
```

## 6. 被动机制：装甲偏置（Armor Deflection）

### 6.1 机制说明

P-40 飞行员座椅后方有厚重的防弹钢板，机身极其坚固。转化为游戏机制：

- **致命判定区**：仅机头驾驶舱位置（Hitbox 半径 4px，保持不变）
- **擦弹区**：机翼范围（Hitbox 外扩 20-30px 的 Area2D），敌弹擦过时不死亡
- **擦弹奖励**：擦弹时产生火花特效 + 微量加分（+50/次）
- **擦弹计数**：连续擦弹可累积 Graze Combo，达到一定次数触发额外奖励

### 6.2 实现方案

在 PlayerBase 场景中新增 `GrazeArea` Area2D 节点（比 Hitbox 大，比飞机 Sprite 小）：

```
Player (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D (机身碰撞，与敌机碰撞)
├── Hitbox (Area2D, 半径4px, 致命判定)
├── GrazeArea (Area2D, 半径30px, 擦弹判定)  ← v1.6 新增
└── ...
```

```gdscript
## v1.6: 擦弹判定区
@onready var _graze_area: Area2D = $GrazeArea if has_node("GrazeArea") else null
## 擦弹计数
var graze_count: int = 0
## 已擦弹的子弹集合（防止同一颗子弹多次触发）
var _grazed_bullets: Array[Node] = []

func _on_graze_area_entered(area: Node) -> void:
    if area is BulletBase:
        var bullet: BulletBase = area as BulletBase
        if not bullet.is_player_bullet:
            # 检查是否已经擦过这颗子弹
            if bullet in _grazed_bullets:
                return
            _grazed_bullets.append(bullet)
            # 擦弹奖励
            graze_count += 1
            add_score(50)
            _spawn_graze_spark(bullet.global_position)
            # 超过一定数量清理集合（防止数组无限增长）
            if _grazed_bullets.size() > 50:
                _grazed_bullets.pop_front()
```

### 6.3 擦弹火花特效

```gdscript
func _spawn_graze_spark(pos: Vector2) -> void:
    # 简单的黄色火花粒子，0.2秒后消失
    var spark: CPUParticles2D = CPUParticles2D.new()
    spark.amount = 5
    spark.lifetime = 0.2
    spark.one_shot = true
    spark.emitting = true
    spark.position = pos
```

### 7.3 落樱漂移弹（drifting_sakura）

**数学逻辑**：子弹发射后附加正弦波横向偏移，模拟樱花飘落。

需要在 `BulletBase` 中新增漂移属性：

```gdscript
## v1.6: 子弹漂移参数（落樱弹用）
@export var drift_amplitude: float = 0.0   ## 漂移幅度（像素）
@export var drift_frequency: float = 0.0   ## 漂移频率
@export var drift_phase: float = 0.0       ## 初始相位
var _drift_time: float = 0.0

func _process(delta: float) -> void:
    if _is_pending_destroy:
        return
    # 基础移动
    position += direction.normalized() * speed * delta
    # v1.6: 正弦波漂移
    if drift_amplitude > 0.0:
        _drift_time += delta
        var drift: float = sin(_drift_time * drift_frequency * TAU + drift_phase) * drift_amplitude * delta
        # 沿垂直于运动方向的向量漂移
        var perpendicular: Vector2 = direction.rotated(PI / 2.0)
        position += perpendicular * drift
    # 屏幕边界检测
    if _is_out_of_screen():
        _destroy()
```

```gdscript
## 回天螺旋死锁：双反向螺旋 + 召唤自杀机
func kamikaze_vortex() -> void:
    var arms: int = 2  # 双螺旋
    var bullets_per_arm: int = int(_get_bullet_param("kamikaze_vortex", "bullets_per_arm", 3))
    var bullet_speed: float = float(_get_bullet_param("kamikaze_vortex", "speed_base", 180.0))

    for arm in range(arms):
        # 螺旋 A: 顺时针; 螺旋 B: 逆时针（+180°偏移 + 反向旋转）

                cos(rad) * 40.0,
                sin(rad) * 40.0

            _spawn_bullet(global_position + spawn_offset, dir, bullet_speed, damage)

    # 概率召唤自杀机
    if randf() < summon_chance:
        _summon_kamikaze()
```
